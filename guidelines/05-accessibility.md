# Accessibility

Accesibilidad mínima para v0. No es el foco principal pero respetamos los básicos.

- **Área tocable mínima:** todos los botones tienen `44×44` o más.
- **Iconos accionables:** todos llevan `accessibilityLabel`.
- **Texto editable:** `<TextInput>` con `accessibilityLabel`.
- **Contraste:** el ramp Arquitectura cumple WCAG AA para `foreground` sobre `background` y `background` sobre `primary`. `secondary` sobre `background` está **al límite** — no usarlo para texto crítico chico.
